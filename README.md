# FuelCalc
A project to track and record fuel mileage, in Python.

First iteration will use a simple CSV style database for recording.

What the program will do:
1. Ask for the car type (or rego)
2. Ask for distance travelled
3. Ask for fuel added
4. Ask for date/time
5. Ask for any notes or conditions during the full load (e.g. lots of highway travel, lots of short trips, etc)

The program will present this in a menu-style with the ability to summarise by car, overall, and the ability to edit or delete entries.
